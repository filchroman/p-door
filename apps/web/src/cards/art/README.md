https://commons.wikimedia.org/wiki/Category:SVG_Atlasnye_playing_cards.

**Лицензия:** CC0 1.0 (общественное достояние) — https://creativecommons.org/publicdomain/zero/1.0/.
Указание автора не требуется, оставлено из уважения.

**Обработка:** `npm run assets:fetch -w @vakhta/web` скачивает ровно эти ревизии (сверка `sha1`) в `source/`
(не коммитится); `npm run assets:build -w @vakhta/web` растеризует их sharp'ом в WebP 240×360, quality 88.
Манифест — `apps/web/scripts/atlas.ts`.
