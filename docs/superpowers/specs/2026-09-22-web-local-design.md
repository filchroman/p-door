# Веб-клиент «Вахта» — локальная игра с ботами (дизайн)

Дата: 2026-09-22
Статус: согласован с заказчиком
Основа: `docs/superpowers/specs/2026-09-22-card-game-design.md` (правила §2, API движка §3.1, экраны §4)

## 1. Цель и рамки

Играбельный веб-клиент, в котором движок работает прямо в браузере: человек играет против ботов. Нужен для локального тестирования правил и интерфейса до появления сервера. Архитектура такая, чтобы сетевой клиент (Socket.io) потом подключился без переписывания экранов.

**Входит:** главная с настройками партии, стол фазы 1 и фазы 2, Вахта, окно штрафа, итоги партии, итоги сессии («Вахтер вечора»), боты, отладочная панель, скеоморфная графика, русские индексы карт.

**Не входит:** сервер, комнаты по коду, вход по ссылке, чат, эмодзи, переподключение, Telegram, Capacitor, украинский язык (но строки лежат в одном словаре).

## 2. Визуальный стиль

Скеоморфизм по образцу «Дурака Онлайн» (референсы от заказчика):
- **Стол:** синее сукно с фактурой (SVG-шум + радиальное затемнение к краям).
- **Карты:** «бумажные», белые, со скруглением и тенью. Индексы по-русски: 2–10, **В** (валет), **Д** (дама), **К** (король), **Т** (туз). Числовые карты — классическая раскладка мастей, рисуется кодом. Фигуры (В/Д/К) — рисунки из свободной колоды Byron Knoll «Vector Playing Cards» (общественное достояние / WTFPL, https://github.com/notpeter/Vector-Playing-Cards); из её SVG берём только центральную картинку фигуры, рамку и индексы рисуем сами.
- **Рубашка:** своя, узор в клетку/ромб (как на референсах), SVG.
- **Игроки:** аватарка в объёмной рамке с именем снизу и плашкой статуса сверху: «Берёт», «Бьёт», «Ждёт отбоя», «Вышел», «Вахта!», «Ходит». Рядом — веер рубашек (число карт) и закрытый прикуп.
- **Нижняя панель:** светлая «пластиковая» плашка: крупная кнопка действия слева, своя аватарка по центру.
- **Экран настроек:** рукописные заголовки (шрифт Marck Script, кириллица), сегментированные переключатели «Игроки 2–6», «Колода 36 / 52», плитки-иконки для «Время хода» и «Затяжной бой», большая кнопка «Играть ▶».
- **Шрифты** подключаются локально (`@fontsource/*`), без внешних CDN.
- **Вёрстка:** вертикальный экран в первую очередь; на широком экране — игровая колонка до 480 px по центру, по бокам сукно.

## 3. Архитектура

```
apps/web/
  src/
    client/        GameClient (интерфейс), LocalGameClient
    host/          LocalHost: состояние, сессия, таймеры, боты
    bots/          мозги ботов (чистые функции)
    store/         zustand-стор клиента (view, events, UI-состояние)
    ui/            экраны и компоненты
    cards/         рендер карт (SVG), ассеты фигур
    i18n/ru.ts     все строки интерфейса
```

**`GameClient`** (то, что потом реализует и сетевой клиент):
```ts
interface GameClient {
  subscribe(listener: (update: ClientUpdate) => void): () => void;
  send(intent: Action): void;          // Action из @vakhta/engine, кроме 'tick'
  me(): PlayerId;
}
interface ClientUpdate {
  view: PlayerView;                    // viewFor(state, me, now)
  events: GameEvent[];                 // события последнего применённого действия
  session: SessionSummary;             // счёт поражений, партия №, вахтер (для итогов)
  players: { id: PlayerId; name: string; avatar: string; isBot: boolean }[];
  deadlines: { turnEndsAt: number | null; penaltyEndsAt: number | null };
}
```

**`LocalHost`** — единственный владелец `GameState` и `SessionState`; делает то, что позже будет делать сервер:
- создаёт партию: колода тасуется `crypto.getRandomValues` и передаётся в `createGame({ deck })`; раздающий/прикупы/первый ход — через `setupNextGame`;
- применяет намерения через `apply(state, id, action, Date.now())`;
- после каждого изменения рассылает подписчикам срез для текущего «я»;
- **таймер хода** (настройка: выкл./15/30/60 с): по истечении — цикл `autoAction` за игрока, пока ход/фаза не сменятся;
- **таймер штрафа** 20 с: по истечении — `autoAction` за всех должников, пока возвращает действия;
- **перепроверка** по `nextDeadline(state)` — отправляет `tick`;
- **боты**: для каждого бота из `pendingPlayers(state)` планирует ход с задержкой (скорость из отладочной панели: 0.3×/1×/3×, базовая пауза 0,6–1,2 с);
- переход к следующей партии (кнопка «Ещё партия») и закрытие сессии (итоги).

`LocalGameClient` оборачивает `LocalHost` и реализует `GameClient`. Переключение «Играть за…» меняет `me()` и пересылает срез.

## 4. Боты (`bots/`)

Чистая функция `botAction(state, playerId, rng, now): Action | null`:
- **Фаза 1:** берёт `autoAction`; с вероятностью 15 % вместо правильного хода делает «ошибку» — тянет из колоды, не переложив обязательную свою карту, или оставляет себе карту, у которой есть цель «+1» у соперника (только если такая ошибка возможна).
- **Вахта:** когда у бота открыто окно (`view.vakhtaOpen`), он с вероятностью 50 % жмёт «Вахта», если в открытых окнах есть нарушение (бот «замечает»), и с вероятностью 3 % — ложный вызов. Реакция 0,8–2,5 с.
- **Штраф:** отдаёт свою самую слабую карту (младший ранг, некозырь в приоритете).
- **Фаза 2:** если можно побить — бьёт самой дешёвой подходящей картой (младший ранг, некозырь раньше козыря); иначе — берёт нижнюю; на пустой стол — заходит младшей некозырной.

Бот видит полное состояние (он часть хоста), но решения принимает только из информации, доступной игроку, кроме «замечания» нарушения — это имитация внимательности.

## 5. Экраны и взаимодействие

1. **Главная / настройки:** поле ника (запоминается в localStorage), настройки партии (игроки 2–6, колода 36/52, время хода выкл./15/30/60, затяжной бой: «Принудительный отбой» / «Конец партии»), кнопка «Играть ▶». Боты получают имена и аватарки из набора.
2. **Стол, фаза 1:**
   - соперники по краю сверху, у каждого — его стопка (видна верхняя карта и высота стопки) и закрытый прикуп; своя стопка и прикуп снизу;
   - колода по центру со счётчиком; тап по колоде — `draw`;
   - вытянутая карта «висит» над колодой; её можно перетащить на любую стопку или тапнуть карту, затем тапнуть стопку-цель (`placeDrawn`);
   - свою верхнюю карту можно так же перенести на стопку соперника (`moveOwnTop`), когда в стопке ≥ 2 карт;
   - **подсказок «+1» нет**: сервер не подсвечивает цели;
   - большая красная кнопка **«ВАХТА!»** появляется, когда `view.vakhtaOpen`; нажатие — `callVakhta`; результат показывается всплывающей плашкой («Вахта! Боря получил фол» / «Ложная тревога»);
   - при выборе козыря — анимация переворота последней карты и значок козыря.
3. **Окно штрафа:** «Боря получил 2 фола — выберите 2 карты для него», своя рука веером, таймер 20 с; у ожидающих — «Ждём, пока соперники выберут штрафные карты» со списком должников (`view.debts`).
4. **Стол, фаза 2:**
   - раскладка как на референсе: соперники сверху, стол по центру (веер карт снизу вверх, нижняя и верхняя выделены), своя рука веером снизу;
   - подходящие карты (`legalMoves`) приподняты и подсвечены, неподходящие приглушены; бить — тап или перетаскивание на стол;
   - в нижней панели кнопка **«Взять нижнюю»** (активна, когда стол непустой), своя аватарка, значок козыря, счётчик «k/N до отбоя»;
   - анимации: карта летит из руки на стол, нижняя — со стола в руку, отбой — стол улетает в сторону, открытие прикупа — переворот;
   - затяжной бой — плашка «Затяжной бой: принудительный отбой» / «Затяжной бой: партия окончена».
5. **Итоги партии:** проигравший (или «Ничья»), «прикуп +1 в следующей партии», таблица поражений сессии, кнопки «Ещё партия» и «Закончить вечер».
6. **Итоги сессии:** «Вахтер вечора» крупно, таблица поражений, кнопка «На главную».

**Отладочная панель** (выдвижная, значок жука; всегда доступна в локальном режиме): «Играть за…» (список мест), «Показать все руки» (карты соперников лицом вверх), скорость ботов, «Автопилот за меня» (моими ходами управляет бот), журнал событий.

Все тексты — в `i18n/ru.ts`.

## 6. Обработка ошибок

- Недопустимое намерение: хост возвращает код ошибки, клиент показывает короткую плашку («Так нельзя: этой картой не побить») и сбрасывает перетаскивание; состояние не меняется.
- Хост ловит исключения движка (ошибка в движке) — показывает «Что-то пошло не так» с кнопкой «Начать заново» и пишет стек в журнал отладки.

## 7. Тестирование

- **Боты (Vitest):** ошибки фазы 1 действительно являются нарушениями; ложные/настоящие вызовы Вахты по вероятностям; жадная логика фазы 2 выбирает самую дешёвую карту.
- **LocalHost (Vitest, фейковые таймеры):** партия и сессия из 3 партий, где все места — боты, всегда доходят до конца; таймер хода делает автоход; таймер штрафа срабатывает; `tick` по `nextDeadline` переводит в фазу 2; «Играть за…» меняет срез.
- **Компоненты (Vitest + Testing Library):** карта рисует русские индексы; кнопка «ВАХТА!» видна только при `vakhtaOpen`; «Взять нижнюю» неактивна на пустом столе; приподняты только `legalMoves`.
- **Сквозной (Playwright):** открыть главную, начать партию 3 игрока / 36 карт, включить в отладке максимальную скорость и «Автопилот за меня», дождаться экрана итогов партии.
